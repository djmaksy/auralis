Поставьте **Auralis** последним на мастер-шину. Он слышит весь готовый микс — каждую полосу
спектра, каждый удар бочки, стереокартину, темп хоста — и превращает его в свет: сияющие озёра,
туманности, неоновые сетки, 3D-вихри частиц и слова песни, которые складываются из частиц в такт голосу.

Когда вы экспортируете звук из DAW, Auralis сам рендерит **MP4 с вашим звуком** кадр за кадром,
вплоть до **4K**. Без захвата экрана, без пропущенных кадров, каждый раз одинаково.

## ✨ Главное

- 🎛 **Работает везде** — VST3-плагин для любой DAW на Windows (Ableton, FL Studio, Cubase, Reaper, Studio One, Bitwig…) и отдельное приложение.
- 🌌 **Слои** — фон, спектр, 3D-частицы, текст, орнаменты, оптика и ваше видео, как слои в графическом редакторе.
- 🎤 **Текст синхронизируется сам** — вставьте слова, и Auralis найдёт их в вокале (17 языков), или загрузите `.lrc`.
- 🔤 **Пять письменностей** — латиница, кириллица, армянская, грузинская и арабская (справа налево, со связным письмом).
- 🎬 **Экспорт без «Create Video»** — просто сделайте баунс трека, и рядом появится MP4.
- 📐 **16:9, 9:16 и 1:1** — вертикальные ролики для Reels/Shorts/TikTok строятся по короткой стороне и не обрезаются.
- 🎨 **62 пресета** — от тихой воды до неоновых кварталов и разлома сферы; можно сохранять свои.
- 🔁 **Кадр в кадр** — время привязано к сэмплам звука, каждый экспорт идентичен.

## 🚀 Быстрый старт

1. **Установите** — запустите `Auralis-<версия>-Setup.exe` из [Releases](https://github.com/djmaksy/auralis/releases/latest).
   Ставятся приложение и VST3-плагин. Windows может показать «Система Windows защитила ваш компьютер» —
   программа пока не подписана: нажмите **Подробнее → Выполнить в любом случае**.
2. **Вставьте** Auralis **последним** эффектом на мастер-шину; при необходимости пересканируйте плагины.
3. **Выберите вид** — пресеты листаются стрелками в шапке.
4. **Добавьте текст** — **Текст…** → вставьте слова → **Применить и синхронизировать**, или бросьте `.lrc` в окно.
5. **Экспорт** — выберите формат, разрешение, fps и битрейт и просто экспортируйте звук из DAW.
   Видео появится в `Видео\Auralis`. В приложении: **Экспорт → Рендер загруженного трека в MP4**.

## ⌨ Горячие клавиши

| Клавиша / действие | Что делает |
|---|---|
| **D** или двойной щелчок по картинке | полный экран |
| **← / →** | предыдущий / следующий пресет |
| **Пробел** | играть / пауза (приложение) |
| Двойной щелчок по ползунку | сброс |
| Правый щелчок по ползунку | модуляция от баса / середины / верха / ударов / громкости / LFO по доле или такту |
| Бросить файл в окно | трек, видео, картинка, `.txt`, `.lrc` или пресет |

## 💻 Системные требования

- Windows 10 или 11, 64 бита
- Видеокарта с OpenGL 3.2 (любая за последние ~10 лет)
- Любая DAW с поддержкой VST3 для плагина; приложению больше ничего не нужно
- Для распознавания текста один раз скачивается модель Whisper (~470 МБ)

Видео кодируется встроенным в Windows Media Foundation (H.264 + AAC). Если рядом с программой
лежит `ffmpeg.exe`, он используется как запасной кодировщик.

<details>
<summary><b>🛠 Сборка из исходников</b></summary>

Нужно: Visual Studio 2022 (C++), CMake 3.22+, Git.

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --target Auralis_VST3 Auralis_Standalone
```

- `build\Auralis_artefacts\Release\Standalone\Auralis.exe` — приложение
- `build\Auralis_artefacts\Release\VST3\Auralis.vst3` — скопировать в `C:\Program Files\Common Files\VST3\`

JUCE и whisper.cpp скачиваются автоматически при первой настройке.

| Опция CMake | Что делает |
|---|---|
| `-DAURALIS_ASIO_SDK=путь\к\asiosdk` | ASIO в приложении |
| `-DAURALIS_WHISPER_VULKAN=ON` | распознавание текста на видеокарте (нужен Vulkan SDK) |
| `-DAURALIS_WITH_WHISPER=OFF` | собрать без распознавания |

Рендер из командной строки:

```bat
Auralis.exe --render song.wav --out video.mp4 --preset 5 --res 1080 --aspect 9:16 --lyrics song.lrc --bitrate 16
```

Каждая отправка в `main` собирается GitHub Actions и публикуется релизом с номером из `VERSION`.

</details>
